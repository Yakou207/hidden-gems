# Hidden Gems: Exposure Allocation Efficiency and Creator Fairness in Recommender Systems

FYP project. Data: KuaiRand-Pure (Gao et al., CIKM 2022), https://kuairand.com/ ,
downloaded from https://zenodo.org/records/10439422 on 2026-11-05 (md5 0820331067a3784d9691136f772b35a7).

## Layout

```
data/raw/          original archive + extracted CSVs. Read-only, never edited; scripts only read from here.
data/processed/    outputs of src/ scripts (parquet). Safe to delete and regenerate.
src/               numbered scripts, run in order
reports/           logs generated by the scripts
```

## Reproduce

The data are not in this repository. Download `KuaiRand-Pure.tar.gz` from the Zenodo link above into
`data/raw/` and extract it there (it creates `data/raw/KuaiRand-Pure/`), then run the scripts in order.
Requires Python 3 with pandas, pyarrow, numpy, scipy, matplotlib and tabulate.

```bash
python3 src/01_profile.py   # -> reports/01_profile.txt
python3 src/02_clean.py     # -> data/processed/*.parquet, reports/02_cleaning_log.md
python3 src/03_prelim_analysis.py  # -> reports/03_prelim_results.md, reports/figures/, data/processed/video_level.parquet
python3 src/04_feasibility_random_shock.py  # -> reports/04_feasibility.md
```

## Processed tables

- `interactions.parquet`: the three logs stacked, with `source` in {random, std_main, std_pre}.
  Added columns: `event_time` (from `time_ms`, Asia/Shanghai), `author_id`, `is_ad`,
  `duration_ms_clean`, `duration_imputed`, `play_ratio`.
- `videos.parquet`: video basic features joined with video statistics (1:1 on `video_id`), plus `is_ad`.
- `users.parquet`: user features; missing codes (-124, "UNKNOWN") converted to NA.

Cleaning decisions and counts: see `reports/02_cleaning_log.md`.
